# CV & Application Tailor

This skill adapts Ivan's base resume and experience into a tailored CV or application message for a specific job, and helps him track document requirements for immigration/visa cases — instead of him rebuilding a CV from scratch or manually re-checking a requirements list each time.

## Background on Ivan (from his Drive)

- 15+ years in renovation, construction, and interior finishing (drywall, filling/skim coating, painting, flooring, wallpaper, demolition, window/door installation).
- Ran his own construction firm, S&S BAU, in Germany for 3 years, managing a 6-person crew: sourcing jobs, estimating, scheduling, quality control, client communication, handover.
- Languages: Ukrainian (native), Russian (fluent), German (working level), Spanish (beginner, learning).
- Target roles: renovation department head, renovation/construction site organizer, crew/contractor coordinator — companies working with real estate, renovation, or property prep for sale/rent.
- Has an active Canada Express Entry immigration case (case number format like "A322174") requiring: language test (IELTS/PTE), employment reference letter(s) with specific duties/dates/hours/salary, WES/ECA assessment, police clearance.

## Workflow

### Tailoring a CV or application message
1. Ask for (or read) the job posting or target role/company.
2. Pull the relevant parts of Ivan's experience and skills — leading with whichever of his strengths (hands-on trade skill vs. crew leadership/organization vs. client-facing estimating) best match what the posting asks for.
3. Produce a tailored CV (using the docx or Google Docs format he already uses) and, if useful, a short outreach/cover message in the language most appropriate to the employer (Ukrainian, German, or English — ask if unclear).
4. Keep claims strictly to what's in his actual background; don't invent employers, dates, or certifications.

### Tracking immigration/visa document requirements
1. Maintain a checklist (matching the structure of his existing "Additional checklist" doc: item, requirement details, status — Provided / Pending) for whichever case he's working on.
2. When he provides a new document or update, mark it Provided and note anything supplementary (e.g. "Provided + Tax Report").
3. When asked, summarize what's still outstanding in one short list so he knows exactly what to chase next.

## Deliverables

Produce the CV as a Word document (via the docx skill) or Google Doc to match his existing files, and the checklist as a simple table. Deliver with SendUserFile, and offer to save alongside his existing CV/checklist files in Drive.

## Notes

- Always show the tailored CV/message before considering the task done — these go to employers or immigration authorities, so accuracy matters more than speed.
- If Ivan hasn't specified which base CV to start from and he has more than one on file, ask which one reflects his current target (e.g. the InvestLife-style renovation-manager version vs. a fresh generic one).
