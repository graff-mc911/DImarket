МІНІМАЛЬНИЙ КРОК ДЛЯ BOLT (1 secret + redeploy)
================================================

1. Push оновлений код на GitHub (graff-mc911/DImarket)
2. Bolt → Secrets → Create secret (ОДИН):

   Name:  VITE_DIMARKET_SUPABASE_ANON_KEY
   Value: anon key з Supabase wjlfvajloxkevggwjgtk → Settings → API

   (URL підставиться автоматично з коду — qwvbb у Bolt можна не чіпати)

3. Bolt → Publish / Redeploy (обовʼязково!)

4. Перевірка: dimarket.market → F12 → Network → має бути wjlfvajloxkevggwjgtk.supabase.co

Без redeploy dimarket.market лишається на СТАРОМУ коді — тому "нічого не змінилось".
